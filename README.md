🐦 Tweedle: A Full-Stack Social Web App

Tweedle is a dynamic Twitter-inspired social media web application built from the ground up using React.js ⚛️ on the frontend and Node.js + Express 🟢 for the server.

It delivers a complete, modern social experience, allowing users to sign up, share real-time posts (tweets), and engage with content and profiles. This project prioritizes smooth state management and persistent data handling for a seamless experience.
